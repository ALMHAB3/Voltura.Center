# فولتورا سنتر — Voltura Center

متجر إلكترونيات بالعربية (لابتوبات، هواتف، شاشات، قطع كمبيوتر، إكسسوارات) مبني بـ Next.js 16 و Tailwind CSS 4 و Supabase.
الأسعار بالدينار الليبي وبدون كسور، والطلب يُؤكَّد مع العميل على واتساب بعد إنشائه.

## المزايا

- **المتجر:** سلايدر بانرات، أقسام شجرية مع قائمة منسدلة (Mega menu) على الكمبيوتر ودرج جانبي على الهاتف، بحث فوري مع اقتراحات يتحمّل الأخطاء الإملائية والفروق بين أ/إ/ا و ة/ه، عروض بعدّاد تنازلي، ماركات، ووضع داكن.
- **صفحة القسم:** فلاتر السعر والماركة والمواصفات والتوفر والعروض، محفوظة في الرابط ليمكن مشاركتها. ترتيب، عرض شبكي أو قائمة، وترقيم صفحات من السيرفر.
- **صفحة المنتج:** معرض صور مع تكبير، جدول المواصفات، الكمية، «أضف للسلة» و«اشترِ الآن»، منتجات مشابهة، وتقييمات لمن استلم المنتج فقط.
- **السلة:** محفوظة في Supabase للمستخدم المسجّل، وفي المتصفح للزائر، وتُدمج عند تسجيل الدخول.
- **الدفع:** كوبون خصم، اختيار المدينة ورسوم توصيلها، والدفع بالكاش عند الاستلام أو حوالة مصرفية أو ون باي أو LyPay. بعد الطلب تظهر صفحة تأكيد برقم الطلب، ثم يُفتح واتساب تلقائياً برسالة فيها تفاصيل الطلب.
- **تتبع الطلب** برقم الطلب ورقم الهاتف بدون تسجيل دخول.
- **الحساب:** تسجيل، دخول، نسيت كلمة المرور، الطلبات وحالتها، العناوين، المفضلة، والبيانات الشخصية. الدخول بـ Google اختياري.
- **لوحة التحكم `/admin`:**
  - إحصائيات اليوم والشهر، والمنتجات القريبة من النفاد.
  - المنتجات مع رفع صور متعددة من جهازك إلى Supabase Storage.
  - الطلبات وتغيير حالتها (الإلغاء يعيد الكميات للمخزون)، والأقسام والماركات والبانرات والكوبونات والمدن ورسوم التوصيل.
  - تقرير المبيعات والأرباح والخصومات لأي فترة.

### قاعدة تقريب الخصم

سعر البيع بعد الخصم يُقرَّب **لأعلى** إلى أقرب مضاعف للرقم 5:

| السعر | الخصم | الحساب | سعر البيع |
|---|---|---|---|
| 100 | 12% | 88 | **90** |
| 100 | 28% | 72 | **75** |
| 100 | 15% | 85 | **85** |

يُحسب في قاعدة البيانات نفسها (`public.discounted_price` وعمود `products.sale_price`)، فيظهر السعر نفسه في كل مكان ولا يمكن تغييره من المتصفح. خصم الكوبون يُطبَّق بعد ذلك على المجموع.

## هيكل المشروع

```
src/
  app/
    (store)/            صفحات المتجر: الرئيسية، القسم، المنتج، السلة، الدفع، الحساب…
    admin/              لوحة التحكم (يتحقق السيرفر من أن الدور admin)
    actions/            Server Actions: السلة، الطلب، الحساب، الأدمن
    api/search/         اقتراحات البحث الفوري
    auth/callback/      إكمال الدخول بـ Google وروابط البريد
    sitemap.ts, robots.ts
  components/           واجهات المتجر والسلة والحساب ولوحة التحكم
  lib/
    site.ts             اسم المتجر وبيانات التواصل وطرق الدفع (عدّلها هنا)
    format.ts           formatPrice: الدالة الوحيدة لعرض الأسعار
    queries.ts          جلب البيانات في Server Components
    validation.ts       مخططات zod للنماذج
    vanex.ts            ربط Vanex (سيرفر فقط)
    supabase/           عملاء Supabase للسيرفر والمتصفح والـ proxy، وأنواع قاعدة البيانات
  proxy.ts              تحديث الجلسة وحماية /admin و /account (اسم middleware في Next.js 16)
supabase/
  migrations/           الجداول، صلاحيات RLS، الدوال (place_order، admin_report…)
  seed.sql              بيانات تجريبية
scripts/create-admin.mjs
tests/e2e/              اختبارات Playwright
public/brand/           الشعار
public/demo/            صور تجريبية للمنتجات والبانرات (للحذف لاحقاً)
```

## التشغيل من الصفر (محلياً)

المتطلبات: Node.js 20.9 أو أحدث، و Docker لتشغيل Supabase المحلي.

1. ثبّت الحزم:

```bash
npm install
```

2. شغّل Supabase محلياً. أول مرة تطبّق الـ migrations والـ seed تلقائياً:

```bash
npx supabase start
```

3. أنشئ ملف الإعدادات ثم انسخ المفاتيح التي يطبعها الأمر السابق (`API_URL` و `ANON_KEY` و `SERVICE_ROLE_KEY`):

```bash
cp .env.example .env.local
```

4. لإعادة بناء قاعدة البيانات من الصفر في أي وقت:

```bash
npx supabase db reset
```

5. شغّل المشروع ثم افتح http://localhost:3000

```bash
npm run dev
```

## إنشاء أول حساب أدمن

الأمر التالي ينشئ الحساب، أو يرقّي حساباً موجوداً إلى أدمن. يستخدم `SUPABASE_SERVICE_ROLE_KEY`، فشغّله على جهازك فقط.

```bash
npm run create-admin -- you@example.com 'كلمة-مرور-قوية'
```

بعدها ادخل من `/account/login` وافتح `/admin`.

بديل يدوي: سجّل حساباً عادياً من الموقع، ثم نفّذ هذا في Supabase ← SQL Editor:

```sql
update public.profiles set role = 'admin'
where id = (select id from auth.users where email = 'you@example.com');
```


اختبارات Playwright تغطي:
- مسار الشراء كاملاً: بحث، فلترة، منتج، سلة، دفع مع كوبون، صفحة التأكيد ورسالة واتساب، ظهور الطلب في لوحة التحكم، ونقص المخزون.
- التسجيل والدخول، ودمج سلة الزائر عند الدخول.
- الأمان: الزائر يُحوَّل لتسجيل الدخول، والعميل العادي لا يفتح `/admin` ولا يقرأ طلب غيره، ولا يمكن تعديل الأسعار أو إنشاء طلب مباشرة من المتصفح.

تعمل الاختبارات على عرضين: كمبيوتر (1366px) وهاتف (360px). تحتاج حساب الأدمن التجريبي `admin@volturacenter.test` / `Admin12345!`، أو غيّره عبر `E2E_ADMIN_EMAIL` و `E2E_ADMIN_PASSWORD`.

## النشر على Vercel مع Supabase حقيقي

1. أنشئ مشروعاً على [supabase.com](https://supabase.com)، ثم اربطه وارفع الـ migrations:

```bash
npx supabase login
```

```bash
npx supabase link --project-ref <PROJECT_REF>
```

```bash
npx supabase db push
```

2. البيانات التجريبية اختيارية. لرفعها إلى المشروع الحقيقي (لا تفعل ذلك إذا كانت لديك بيانات حقيقية):

```bash
npx supabase db push --include-seed
```

3. في Supabase ← Authentication ← URL Configuration:
   - ضع `Site URL` = رابط موقعك.
   - أضف `https://<موقعك>/auth/callback` إلى Redirect URLs.
4. اختياري، الدخول بـ Google: فعّل Google في Authentication ← Providers، ثم ضع `NEXT_PUBLIC_GOOGLE_AUTH=true`.
5. على Vercel: استورد المستودع، وأضف متغيرات البيئة التالية من Supabase ← Project Settings ← API، ثم انشر:
   - `NEXT_PUBLIC_SITE_URL`
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`: لا تضع قبله `NEXT_PUBLIC_`. التطبيق لا يستخدمه، ويحتاجه فقط سكربت إنشاء الأدمن.
6. أنشئ حساب الأدمن بالسكربت، بعد وضع مفاتيح المشروع الحقيقي في `.env.local`.

## ما يجب استبداله بمحتواك الحقيقي

| ماذا | أين |
|---|---|
| المنتجات الـ40 التجريبية (أوصافها تبدأ بـ «منتج تجريبي») | لوحة التحكم ← المنتجات (احذفها وأضف منتجاتك) |
| صور المنتجات والبانرات التجريبية | ارفع صورك من لوحة التحكم، ثم احذف مجلد `public/demo` |
| البانرات الثلاثة | لوحة التحكم ← البانرات |
| رسوم التوصيل ومدته لكل مدينة | لوحة التحكم ← المدن والتوصيل |
| الكوبون التجريبي `VOLTURA10` | لوحة التحكم ← الكوبونات |
| رقم الحساب المصرفي، رقم ون باي، حساب LyPay | `src/lib/site.ts` ← `paymentMethods` |
| نص «من نحن» وسياسة الإرجاع (مسودات) | `src/app/(store)/about` و `src/app/(store)/return-policy` |
| بيانات التواصل وحسابات التواصل | `src/lib/site.ts` |

## Vanex

الربط جاهز من جهة السيرفر (`src/lib/vanex.ts`). المفتاح لا يصل للمتصفح أبداً.

1. ضع `VANEX_API_URL` و `VANEX_API_KEY` في إعدادات Vercel.
2. أدخل رقم كل مدينة في Vanex من «المدن والتوصيل».
3. يظهر في صفحة الطلب زر «إنشاء شحنة في Vanex».

**مهم:** لم تكن وثائق Vanex متاحة أثناء البناء، فشكل الطلب المرسل عام. طابقه مع وثائقهم قبل الاستخدام. حتى ذلك الحين يمكنك كتابة رقم التتبع يدوياً في صفحة الطلب.
